# Real Project Screenshots Upload Location

To replace the high-resolution conceptual UI architecture previews with real screenshots of your applications:

1. Drop your image files here (e.g. `analytics.png`, `ecommerce.png`, `sentiment.png`).
2. Update the `image` field in `/src/data/portfolioData.ts` for the corresponding project.

Example:
```ts
{
  id: 'analytics-dashboard',
  title: 'Real-Time Analytics Dashboard',
  image: '/projects/analytics.png',
  ...
}
```
